# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub instead: go to the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it and which version you tested. You'll get a reply within a few days, and once a fix is released you'll be credited unless you'd rather not be.

## Before you expose it

Headless Music Player has no login: anyone who can reach it can control playback, change the queue and rescan the library. Keep it on a private network, or put it behind a VPN or an access proxy. Don't forward port 8000 from your router.

## Supported versions

Headless Music Player is pre-release. Fixes go into the latest release only.
